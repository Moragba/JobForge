# JobForge – AI Application Generator

JobForge ist eine intelligente Fullstack-Anwendung zur automatisierten Erstellung maßgeschneiderter Bewerbungsunterlagen mittels LLM-Pipeline.

## Dokumentation
Die vollständige Produktdokumentation (PRD), Architektur und Aufgabenverfolgung befinden sich in unserem Atlassian Workspace:
* 🚀 **Projekt-Dashboard & Roadmap:** [Confluence Space: JobForge](https://auspo.atlassian.net/wiki/spaces/JobForge/overview?homepageId=35651753)
* 📄 **Product Requirements Document:** [JobForge PRD](https://auspo.atlassian.net/wiki/spaces/JobForge/pages/35815426/PRD+Product+Requirements+Document) 

## Tech Stack
* **Backend:** Spring Boot (Java) 
* **Frontend:** React 
* **AI Engine:** OpenAI API,  Gemini API oder andere LLM API
